# Character portrait references

Each PNG is a lossless crop from the user-supplied character-grid screenshots. The
matching metadata, including canonical names, aliases, source indices, and source
pixel bounds, is in `../portrait-atlas.json`.

These references are for character-image matching only. A dim or bright source crop
is a property of the supplied screenshot; it does not express account ownership,
unlock status, level, sequence, or any other player state.
